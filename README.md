# TaxIn60Sec

Modern tax and compliance platform built using Next.js, Spring Boot, and PostgreSQL.

## Features
- Responsive modern UI
- Spring Boot REST API
- PostgreSQL integration
- Contact form persistence
- Full-stack architecture

## Tech Stack
Frontend:
- Next.js
- Tailwind CSS
- Framer Motion

Backend:
- Spring Boot
- Spring Data JPA
- PostgreSQL

## Run Locally

Frontend:
npm run dev

Backend:
./mvnw spring-boot:run
